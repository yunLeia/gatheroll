# 업로드가 이벤트 공유가 되는 제품 규칙

- 문제: 기존 문서는 업로드 후 별도 공유 확인을 요구했지만, 사용자가 원하는
  흐름은 사진 선택 후 업로드하면 이벤트에 공유되는 것이다.
- 원리: `AGENTS.md`와 ADR 008에 새 규칙을 기록했다. 현재
  `apps/api/src/gatheroll_api/photos.py`는 여전히 본인의 사진만 반환하며,
  `domain.py`의 `uploaded_private` 값도 그대로다. 문서 변경과 접근 권한
  구현은 서로 다른 작업이다.
- 이유: 이미 선택한 사진을 공유하려고 업로드하는 사용자에게 두 번째 확인
  단계를 요구하지 않기 위해서다.
- 가장 단순한 구현 방향: 다음 갤러리 작업에서 이벤트에 묶인 권한 검사,
  썸네일 목록, 요청 시 원본 다운로드 URL을 추가한다. R2 공개 버킷은 필요 없다.
- 주의점: 업로드 후 실행하는 AI는 이미 공유된 사진의 사전 필터가 될 수 없다.
  기존 비공개 안내를 보고 올린 사진의 처리와 업로드 버튼 안내도 갤러리 구현 전에
  정해야 한다. 이번 작업은 문서만 수정했으며 실행 테스트는 하지 않았다.
